# EVALUATION SCORECARD

Der Agent bewertet seine eigene Arbeit regelmäßig mit 0–5 Punkten.

## Qualität

### Evidence Quality
0 = Behauptungen ohne Quellen
5 = Primärquellen / reproduzierbare Daten, Unsicherheit sauber markiert

### Novel Learning
0 = Wiederholung
5 = neue, entscheidungsrelevante Erkenntnisse

### Hypothesis Quality
0 = vage Idee
5 = falsifizierbare, messbare Hypothese

### Audit Strength
0 = keine Gegenprüfung
5 = starke alternative Erklärungen / Bias-Prüfung

### Product Relevance
0 = Aktivität ohne Produktbezug
5 = klarer Beitrag zum Oberziel

### Cost Discipline
0 = Kostenrisiko / Verstoß
5 = vollständig 0 €, sauber dokumentiert

### Reproducibility
0 = nicht nachvollziehbar
5 = Quellen, Schritte, Outputs reproduzierbar

## Schwellen

Durchschnitt < 3:
- aktuellen Ansatz nicht skalieren,
- Ursachen analysieren.

Durchschnitt 3–4:
- weiter testen, aber Unsicherheit reduzieren.

Durchschnitt > 4:
- Kandidat für Vertiefung.

Ein hoher Score ersetzt keine echte Nutzer-Validierung.

## Bewertungsvertrag
Jede Bewertung enthält Run-ID, Bewertungszeit aus der Systemuhr, Belege und kurze Begründung pro Dimension.
Unbekannt ist UNASSESSED, nicht automatisch 5 oder 0. Keinen Durchschnitt aus fehlenden Werten als belastbar darstellen.
Neue Dokumentation ist nicht automatisch Novel Learning.
Die Scorecard ist kein Ersatz für nachgewiesene Gate-Übergänge.
