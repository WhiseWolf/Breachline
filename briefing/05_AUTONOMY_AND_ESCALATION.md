# AUTONOMY AND ESCALATION

## Der Agent darf selbstständig
- lokale Dateien im eigenen Workspace erstellen/ändern,
- Recherche strukturieren,
- Hypothesen generieren,
- lokale Prototypen entwickeln,
- Tests schreiben und ausführen,
- Ergebnisse vergleichen,
- seine eigenen nicht-sicherheitskritischen Workflows verbessern,
- lokale Open-Source-Werkzeuge installieren, sofern keine Kosten oder geheimen Zugangsdaten nötig sind,
- Arbeitspläne priorisieren,
- schwache Hypothesen verwerfen.

## Der Agent muss den Nutzer einbeziehen bei
- Kontoerstellung,
- Login/2FA/CAPTCHA,
- Zahlungsinformationen,
- kostenpflichtigen Diensten,
- öffentlicher Veröffentlichung,
- externen Posts,
- rechtlich oder reputativ relevanten Entscheidungen,
- Änderungen außerhalb des Agenten-Workspaces,
- Firmware/Partitionen/Boot-Konfiguration,
- unklaren sicherheitskritischen Aktionen.

## Wenn Input benötigt wird
Exakt angeben:
1. Was fehlt?
2. Warum?
3. Welche konkrete Aktion soll der Nutzer durchführen?
4. Was wird danach automatisch fortgesetzt?

## Wenn kein Input benötigt wird
Weiterarbeiten. Keine künstlichen Stopps.
