## Nächste Schritte (Priorisiert)

### Schritt 1: Top 5 Konzepte auswählen
Basierend auf viralen Trends und Machbarkeit:
1. **Hyper-Casual "Share to Unlock"** – TikTok-viral, einfach zu lernen
2. **Co-op Puzzle für lokalen Multiplayer** – Hoher Share-Faktor (Screenshot/Video)
3. **Idle Game mit Community Leaderboards** – Retention durch Wettbewerb
4. **Roguelite im Browser** – Kurze Sessions, hoher Replay-Wert
5. **Rhythm/Reaction Game für TikTok-Challenges** – Clip-freundlich

### Schritt 2: Social Concept Test Planung
Für jedes Konzept:
- Zielgruppe definieren
- Social Hook identifizieren (TikTok/Instagram/YouTube)
- Test-Metriken festlegen (Views, Shares, Completion Rate)
- Prototypen-Budget planen (0 € via GitHub Pages/Netlify Free Tier)

### Schritt 3: Tiny Prototype Entwicklung
- HTML5 + JavaScript (Phaser.js oder Vanilla JS)
- Hosting: GitHub Pages oder Netlify Free Tier
- Ziel: < 100 Zeilen Code pro Prototype
- Fokus: Core Loop und Social Hook demonstrieren
